Inside the decision brain

Every decision is made by Findability Sciences Engines. The voice layers only translate audio to text and back.

FS Engine 1

Language Coach Engine

Detects the caller's language and sets the reply language, so the agent mirrors how the customer speaks.

FS Engine 2

Policy Engine

The core decision maker. Chooses the next response from verified facts and collections rules, and triggers actions: promise to pay, callback, dispute, hand-off.

FS Engine 3

Supervisor Engine

Reviews every turn for compliance and tone, flags issues for the team, and enforces guardrails.

Knowledge base

Verified account data

Live customer, invoices, balances, payment methods and notes. The only facts the agent may speak.

One approved reply Exactly one verified response string is released to be spoken.

Key principles

Four rules govern the whole system, on every call, on every channel.

The brain decides

The voice layers only translate. Neither one ever decides what the agent says.

One source of truth

The agent can only state facts that exist in the verified knowledge base.

Every turn supervised

Compliance and tone are checked on each response before and as it is delivered.

Channel agnostic

Web and phone callers share one decision path. Only the audio transport differs.

Summary: speech becomes text, the Findability Sciences Engines decide the response from verified account data and business policy with a Supervisor reviewing every turn, and only the approved reply is spoken back to the caller.
